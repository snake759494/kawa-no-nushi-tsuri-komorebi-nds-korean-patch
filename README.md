# 강의 낚시꾼: 나무 그늘 골짜기·시냇물의 노래 NDS 한글패치 1.0.0

일본판 『川のぬし釣り こもれびの谷 せせらぎの詩』(Marvelous Interactive, 2007)의 한국어 패치입니다. 대사·메뉴·설명과 그림 글자를 외부 기계 번역 없이 직접 번역했습니다.

## 파일과 적용
릴리즈의 `Kawa_no_Nushi_Tsuri_KR.xdelta`를 원본 ROM에 적용합니다. 원본은 일본판 ANYJ이며 SHA-256은 다음과 같습니다.

`97de248e676e6e340073c84bc2f25c71b9697e1e0e157f47e2baba52ce181db0`

```powershell
.\xdelta.exe -d -s "Kawa no Nushi Tsuri - Komorebi no Tani, Seseragi no Uta (Japan).nds" Kawa_no_Nushi_Tsuri_KR.xdelta "강의낚시꾼_한국어.nds"
```

결과 ROM SHA-256: `3869e429a33cf05a14e76ac0c7a66eead613c54a1da46c9e1ce7f014621f8389`. 패치는 `-0 -S none`으로 생성했고 복원 결과의 해시 일치를 확인했습니다. ROM은 배포하지 않습니다.

## 번역 범위
- 대사 스크립트(`script_data.bin`) 298개의 텍스트·선택지 명령 4,235개(고유 문장 2,731개) 전부 번역(미번역 0). 길이가 바뀌면 명령을 다시 배치하고 점프 주소를 고쳤습니다.
- 아이템 도움말 84개, 작업 메모 35개, 물고기·곤충 도감 설명 146개.
- ARM9 메뉴·저장·Wi-Fi 대회 안내·아이템/물고기 이름·퀘스트 제목 문자열 812개. 원래 문자열 공간 안에서 재배치하고 포인터를 고쳤습니다.
- 화자 이름표 23개, 대회 종류 문구, 이름 입력 키보드(한글 2페이지 180자 + 영문·숫자·기호 페이지, 완성형 선택 방식).
- 그림 글자: 타이틀 로고(대·소), 타이틀·Wi-Fi 대회·친구 코드 메뉴 막대 24개, 메뉴 버튼 8개, 「뒤로·메뉴·그만」 라벨, 이름 입력 화면, 창 제목 14개·지명·시간대·순위(모든 사본), 필드 상태창, 아이템·낚시 도구·조과 기록·친구 리스트 화면, 대회 종류 막대, 낚시 튜토리얼 라벨 6개, 모드 막대, 미끼 종류 라벨.

## 폰트
- 본문 12px: 나눔스퀘어 네오 cBd를 원본처럼 3단계 안티앨리어싱으로 양자화해 16×16 셀에 넣었습니다. 본 폰트 862자(아이콘 칸 0x3b4~0x3ff 보존)와 도감 화면 보조 뱅크 46자.
- 제목·버튼·로고: 나눔스퀘어 네오 dEb/eHv. 9px 이하 작은 라벨: 갈무리9.

## 구조 메모
- `.rln`: "같은 바이트 2개 + 추가 반복 수" RLE(ARM9 0x02097f90).
- arc 항목: 0x20바이트 헤더(이름8·플래그·유형·크기). 유형 0은 선형 비트맵, 2는 16×16 글자 시트, 1·3·4·6은 타일, 7·8·9·10은 팔레트.
- 텍스트는 글리프 인덱스 u16(0x8001 줄바꿈, 0x8002 페이지, 0x800d 주인공 이름 등). SJIS 문자열은 ARM9 0x122ac4 표의 앞 908자에서 검색해 변환.
- 메뉴 막대 스프라이트는 32×32 1D, OBJ 경계 128바이트이며 시트 안에 0x1000 간격으로 저장됩니다.

## 검증과 한계
- 창 없는 DeSmuME 코어를 내부 입력 API로 조작해 콜드 부팅, 타이틀, 이름 입력, 첫 이벤트 대사, 필드 상태창, 메뉴와 하위 화면, 낚시 튜토리얼과 대결을 확인했습니다. Wi-Fi 대회 메뉴 막대는 그래픽 렌더링으로만 확인했습니다. 전체 플레이·실기 검증은 하지 않았습니다.
- `dwc/utility.bin`은 닌텐도 공용 Wi-Fi 커넥션 설정 프로그램이라 범위에서 제외했습니다.
- **남은 미번역**: 후반 장소의 이름판 그림(`pt_26_t`), 낚시 중 효과음 글자(「グイ!」 등), 엔딩 스태프롤 그림.

## 재현
Python 3.13과 `requirements.txt`. 원본 ROM을 상위 폴더에 두고 `tools/extract_files.py`, `tools/extract_script.py`, `tools/make_ja.py`로 원문 목록을 만든 뒤 `tools/build.py`로 빌드합니다. 번역 원고는 `trans/ko_*.tsv`·`fix_*.tsv`, 용어집은 `trans/glossary.tsv`입니다. 화면 덤프 기반 그림 패치(`trans/gfx_patches.json`)는 원본 ROM으로 해당 화면을 띄워 `tools/emusrv.py`로 만든 덤프가 `dumps/`에 있어야 적용됩니다(원작 그래픽이라 저장소에 포함하지 않음).
